# Network Traffic Filtering System

A course project for the **Object-Oriented Analysis and Design** module.

The project focuses on designing a network traffic filtering system based on configurable filtering policies and rules. It includes UML diagrams and a C# implementation that demonstrates object-oriented design principles.

## Project Structure

The repository is organized into directories according to the laboratory assignment numbers. Each directory contains the diagrams, documentation, and source code related to the corresponding assignment.

## Technologies

- C#
- UML
- diagrams.net (draw.io)

## Functionality

- Configurable traffic filtering policies
- Rule-based packet filtering
- Allowing or blocking network packets
- Filtering result logging
